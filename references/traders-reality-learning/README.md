## תהליך קליטת מקור נוסף — ללא אוטומציה וללא פיתוח

1. אפשר לנתח במחזור 3–5 תמלולים, ואף יותר לפי הצורך, תוך בדיקת כפילויות ודיווח על מידע חדש בלבד; לא צופים אוטומטית בכל הרשימה.
2. מתעדים מספר סרטון, כותרת, תמלול/זהות מקור (אם זמין), חותמות זמן, **מה נאמר** והאם נדרשת הסתכלות בגרף עצמו.
3. מסווגים: **א. עובדה נצפית בתמלול**; **ב. פרשנות/טענה של המדריך**; **ג. השערה שלנו**; **ד. הכרעת מחקר**. לא ממירים טענת עושי שוק למשתנה נצפה.
4. בודקים כפילויות מול האפליקציה והמחקרים שכבר נסגרו; כותבים רק שינוי לממצא קיים או ראיה חדשה/סותרת.
5. בוחרים `keep / unclear / reject / already-covered`. רעיון ללא כללי זמן אמת, עלות וסיכון נשאר **לא מאושר**.
6. משנים תיעוד רק בענף ייעודי ובהרשאה; אין מיזוג אוטומטי ל־`main`.
