These clock, stop and target choices are an engineering proxy, not asserted exact published Tino execution code.

Economics:
- grossR = direction × (X − E) / D.
- CostR = [0.001 × E + 0.0001 × (E + X)] / D, deducted once.
- LONG mirrored barriers: stop E−D, target E+2D.
- SHORT mirrored barriers: stop E+D, target E−2D.
- E, D and all barriers must be finite and positive with valid directional ordering; invalid geometry excludes the whole pair before outcomes.
- Null = average adjusted mirrored-arm return; delta = strategy minus null.
