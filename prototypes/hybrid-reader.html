Request bounds & clock meaning

At most 17 public requests per click: one server-time request, three closed-history pages and one provisional sample for each timeframe. 1,000 rows/page, target 3,000 closed candles. No automatic retry, polling, WebSocket, background refresh or storage. Request timeouts only: 12 seconds each; batch abort at 120 seconds. Failures stay unavailable until you refresh.

The cutoff is the latest completed 5m UTC boundary at the captured Binance server time. Each timeframe uses its own latest closing boundary no later than that cutoff. Local receipt time is the device's clock, not exchange event time. Provisional elapsed time is a frozen estimate using server time plus monotonic elapsed time; request latency remains uncertain.

Calculation provenance, semantics & limitations

This standalone reader contains no directional decision, score, plan, journal, or execution system. Price is USDT per BTC; trade volume is BTC. Candle direction is open-to-close, not measured buy/sell flow. All values are factual observations or explicitly identified calculations.

EMA5/13/50/200/800 reuse the existing first-value EMA seed. A value is withheld until at least its period of consecutive closes. EMA800 is always a finite-history approximation: remaining initial-seed weight is (1 − 2/801)^(n−1). This is a mathematical weight, not market-price error. At least 3,000 candles are targeted; 3,000 do not establish platform or feed parity. Gaps restrict calculations to the latest contiguous valid suffix, and the actual origin/count is shown.

PVSRA uses the prior ten closed candles: Climax if volume ≥2× mean OR volume×range ≥ prior maximum; otherwise Rising if volume ≥1.5× mean; otherwise Regular. A vector may qualify by volume×range despite a small volume ratio. Missing/zero/invalid references stay unavailable. A doji is shown as DOJI; source-zone provenance uses strict close > open, so equal open/close maps to source DOWN.

Source-derived zones use body-only original bounds, body-with-wicks shrinking, both arrays, Rising and Climax sources, and cap 500 per array before safe cleanup. Creation uses the previous qualifying candle and is processed only on the next CLOSED candle. Strict-interior touches shrink remaining bounds; far-edge equality/crossing deletes. Original and remaining bounds stay separate. Nearest means distance to the remaining near edge; exact-price ties retain individual identity. No original-color target restriction. A zero-distance near-edge touch can remain open.

Differences from supplied Pine: this is a qualified CLOSED-only projection, delayed versus intrabar drawing; it refuses unavailable/zero reference strength and zero-width bodies; cleanup safely compacts unavailable entries instead of reproducing possible forward-loop indexing defects; native drawing-object lifecycle/garbage collection and color collisions are not reproduced. Only the fixed reviewed profile is implemented. No claim of TradingView runtime parity. The supplied Pine files have not been copied into this reader.

No zone beyond the loaded history can be reconstructed. “None in loaded history” is not a clear-path claim. An outage or stale candle is not replaced with Spot/Mark/index data. UTC daily opening price requires its actual 00:00 5m candle; previous-day pivots require all 288 consecutive valid closed 5m candles.
